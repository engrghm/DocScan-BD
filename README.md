# DocScan BD — স্মার্ট ডকুমেন্ট স্ক্যানার ও ডেটা এক্সট্র্যাক্টর 📱🇧🇩

**DocScan BD** হলো একটি মোবাইল-ফার্স্ট ওয়েব অ্যাপ্লিকেশন, যা বিশেষভাবে আইফোন ও স্মার্টফোনের মাধ্যমে বাংলাদেশের যেকোনো অফিসিয়াল ডকুমেন্ট স্ক্যান, অপটিক্যাল ক্যারেক্টার রিকগনিশন (OCR) এর মাধ্যমে বাংলা ও ইংরেজি টেক্সট শনাক্তকরণ, নির্দিষ্ট ফিল্ডসমূহ ফিল্টার করে এক্সট্রাক্ট করা এবং সরাসরি **Google Sheets**-এ ক্রমান্বয়ে স্বয়ংক্রিয়ভাবে সংরক্ষণ করার জন্য ডিজাইন করা হয়েছে।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

### ১. মাল্টি-আপলোড ও কন্টিনিউয়াস ব্যাচ স্ক্যান (Multi-Upload & Continuous Batch Scan)
- ক্যামেরা দিয়ে একটানা একাধিক পাতা বা ডকুমেন্ট স্ক্যান করার সুবিধা।
- গ্যালারি বা ফাইল ম্যানেজার থেকে একসাথে একাধিক ছবি/ডকুমেন্ট এক ক্লিকে আপলোড করার সুবিধা।

### ২. একক ব্যক্তি মোড — এক রো / Same SL (Single-Person Row Consolidation)
- **একই ব্যক্তির একাধিক ডকুমেন্ট** (যেমন: জাতীয় পরিচয়পত্র + জমির দলিল ও খতিয়ান + বিল্ডিং এরিয়া ও তলার তথ্য) স্ক্যান বা আপলোড করলে সব ডকুমেন্ট থেকে ডেটা মার্জ হয়ে **একটি রো-তে একই SL নম্বরে** তৈরি হয়।
- শুধুমাত্র আপনার বাছাইকৃত / টিক দেওয়া নির্দিষ্ট ফিল্টারকৃত তথ্যগুলো গুগুল শিটে পাঠানো হয়।

### ৩. ধারাবাহিক SL ও পরবর্তী ব্যক্তির ডেটা সংযোজন (Sequential SL & Multi-Person Pipeline)
- প্রতিটি ব্যক্তির রেকর্ড একটি নির্দিষ্ট ক্রমিক নম্বর (`SL: 1`, `SL: 2`, `SL: 3`...) ধারণ করে।
- একজনের তথ্য Google Sheets-এ সেভ হওয়ার সাথে সাথে অ্যাপ পরবর্তী ব্যক্তির জন্য প্রস্তুত হয় এবং একই শিটের পরবর্তী রো-তে নতুন SL দিয়ে ডেটা যোগ করে (পূর্বের ডেটা অক্ষত থাকে)।
- **"➕ পরবর্তী ব্যক্তির স্ক্যান শুরু করুন"** বাটন দিয়ে এক ক্লিকেই পূর্বের ব্যাচ ক্লিয়ার করে নতুন ব্যক্তির স্ক্যান শুরু করা যায়।

### ৪. সমর্থিত ডকুমেন্টের ধরন (Supported Document Types)
1. **জাতীয় পরিচয়পত্র (National ID / NID):** নাম (বাংলা/ইংরেজি), NID নম্বর, জন্ম তারিখ, পিতা/মাতার নাম, ঠিকানা, রক্তের গ্রুপ, জমির খতিয়ান, দলিল নং, বিল্ডিংয়ের মোট এরিয়া, ভবনের তলা, ভবনের ধরন।
2. **জমির দলিল ও খতিয়ান (ভূমি/ভবন - Land Deed & Property):** জমির খতিয়ান, দলিল নম্বর, বিল্ডিংয়ের মোট এরিয়া, কত তলা (ভবনের তলা), ভবনের ধরন, জমির/ভবনের মালিকের নাম, মালিকের এনআইডি নম্বর, মৌজা ও দাগ নম্বর, সম্পত্তির ঠিকানা/অবস্থান, দলিল/নিবন্ধনের তারিখ।
3. **ট্রেড লাইসেন্স (Trade License):** লাইসেন্স নম্বর, প্রতিষ্ঠানের নাম, মালিকের নাম, ব্যবসার ধরন, ঠিকানা, ইস্যু তারিখ, মেয়াদ।
4. **ই-টিআইএন সার্টিফিকেট (e-TIN Certificate):** টিআইএন নম্বর, করদাতার নাম, এনআইডি নম্বর, কর সার্কেল, কর অঞ্চল।
5. **ভ্যাট/বিআইএন সার্টিফিকেট (VAT/BIN Certificate):** বিআইএন নম্বর, প্রতিষ্ঠানের নাম, মালিকের নাম, সার্কেল, কমিশনারেট।
6. **ব্যাংক সার্টিফিকেট (Bank Certificate):** অ্যাকাউন্ট নম্বর, অ্যাকাউন্ট হোল্ডার, ব্যালেন্স, ব্যাংক ও শাখার নাম।
7. **এফিডেভিট ও ডিক্লেয়ারেশন (Affidavit & Declaration):** ঘোষণাকারীর নাম, এনআইডি, নোটারি নম্বর, সাক্ষী ১ ও ২।
8. **অন্যান্য ডকুমেন্ট (Other Documents):** ডকুমেন্টের শিরোনাম, জারিকারী, রেফারেন্স নম্বর, নোট।

### ৫. মাল্টি-কি Google API পুল ও অটো ফেইলওভার (Google API Pool & Auto Failover)
- একাধিক Google Cloud Vision / Gemini API Key সংরক্ষণ করার সুবিধা।
- যেকোনো একটি API Key এর লিমিট শেষ হলে বা ব্যর্থ হলে স্বয়ংক্রিয়ভাবে পরবর্তী API Key-তে সুইচ করার সুবিধা (Auto-Failover / Random Load Balancing)।

### ৬. অফলাইন সিঙ্ক কিউ ও এক্সপোর্ট (Offline Sync Queue & Multi-Format Export)
- ইন্টারনেট সংযোগ বিচ্ছিন্ন থাকলে তথ্য স্থানীয় সিঙ্ক কিউতে জমা থাকে এবং পুনরায় চেষ্টা করা যায়।
- এক্সপোর্ট সুবিধা: **Google Sheets**, **Excel-বান্ধব UTF-8 CSV**, এবং **PDF ডকুমেন্ট**।

## 🚀 কীভাবে ব্যবহার করবেন (Quick Start)

### ১. লোকাল ডেভেলপমেন্ট
প্রজেক্টটি সম্পূর্ণ স্ট্যাটিক ওয়েব ফাইল (HTML, CSS, JS) নিয়ে গঠিত। যেকোনো ওয়েব সার্ভারে সরাসরি চলে:

```bash
# Python দিয়ে সার্ভার চালু করতে:
python -m http.server 8080

# অথবা Node.js live-server দিয়ে:
npx serve .
```
ব্রাউজারে যান: `http://localhost:8080`

## 📊 Google Sheets সংযোগ পদ্ধতি (Apps Script Setup)

১. [Google Sheets](https://sheets.google.com)-এ গিয়ে একটি নতুন স্প্রেডশিট খুলুন।
২. মেন্যু থেকে **Extensions** → **Apps Script** নির্বাচন করুন।
৩. এই রিপোজিটরির `google-apps-script.js` ফাইলের সম্পূর্ণ কোডটি পেস্ট করুন।
৪. **Save (Ctrl + S)** করুন।
৫. ডান পাশের উপরে **Deploy** → **New deployment** ক্লিক করুন:
   - **Type:** `Web app`
   - **Description:** `DocScan BD Sync`
   - **Execute as:** `Me`
   - **Who has access:** `Anyone`
৬. **Deploy** বাটনে ক্লিক করে প্রাপ্ত **Web app URL** টি কপি করুন।
৭. DocScan BD অ্যাপের সেটিংস বা সেভ বাটনে লং-প্রেস করে **Webhook URL** ঘরে পেস্ট করে সংরক্ষণ করুন।
